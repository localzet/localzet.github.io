# Localzet Atlas · инженерный атлас

Русскоязычная открытая энциклопедия об устройстве компьютерных систем: Linux, Git, Docker, DevOps, архитектура ПО, ассемблер, Интернет и криптография, Python, Bash/Zsh, PHP и ИИ в разработке.

**Сайт:** https://localzet.github.io/academy/

## Принципы

- Объяснения через исторические предпосылки, механизмы, реальные команды, практические задания и первичные спецификации.
- Страница курса отдельно показывает уже написанные главы и **темы в плане**. Не выдаём оглавление за готовый курс.
- Факты, стандарты, номера RFC проверяются по официальным документам. Синтаксис и параметры следует сверять с версиями конкретных утилит.
- Бесплатно, по-русски, без регистрации. Прогресс чтения хранится только локально в браузере.

## Структура

- `academy/index.html` — статическая точка входа для GitHub Pages;
- `academy/assets/style.css` — адаптивный дизайн без зависимостей;
- `academy/assets/app.js` — клиентская навигация, поиск и отметки чтения;
- `academy/assets/theme.js` — независимая инициализация и сохранение темы;
- `academy/content.js` — каталог исходных направлений и первоисточников; дополнительные направления добавляются в `subjects/programming.js`;
- `academy/subjects/*.js` — 186 опубликованных глав (полные редакции), разделённые по предметам;
- `academy/editorial.js` — учебные цели, определения терминов, схемы и контрольные вопросы;
- `academy/levels.js` — 96 самостоятельных редакций Junior, 7 дополнений Senior, отдельные словари и схемы, порядок и минимальный уровень каждой главы, программы God;
- `academy/figures.js` — 36 авторских SVG-иллюстраций ключевых механизмов;
- `academy/reference.js` — поисковый каталог из 489 команд Linux, Git и Docker;
- `academy/tests/validate.mjs` — автоматическая проверка связности глав, источников и загрузки;
- `academy/tests/browser.cjs` — браузерные регрессии Playwright на мобильных и настольных разрешениях в обеих темах.

Это независимый раздел существующего сайта: развёртывание автоматически сохраняет и раздел `/weather/`.

**Важное ограничение:** Пункты программы — план охвата, а не написанные главы. Количество готовых материалов отображается отдельно. Полная детализация каждой подсистемы — долгосрочная редакционная работа, текущие тексты являются фундаментальной редакцией. Каталог команд покрывает 489 основных интерфейсов с назначением и ссылками на документацию, для 94 интерфейсов Linux дополнительно описаны 263 выбранных параметра и подкоманды. Полный список зависит от версии утилиты и остаётся в её официальной справке.

## Русский язык и терминология

Используем принятые в IT термины (коммит, merge-коммит, production, rebase, pull request), а не искусственные кальки. При первом появлении в материале для новичков объясняем смысл по-русски. Названия команд, опций и программ сохраняем без перевода. Заголовки практических заданий оформляем как «Практика». Проверяем падежи, согласование и естественность формулировок.

## Практические статьи

`academy/articles.js` — самостоятельные руководства по discovery, ТЗ, архитектуре, выбору стека и БД, Git в команде, сборке дистрибутива и coding agents. Маршруты `#/articles` и `#/article/<id>` доступны независимо от уровня курса; статьи индексируются поиском. `academy/subjects/programming.js` добавляет четыре направления, начальные редакции, словари и источники. `academy/assets/labs.js` содержит шесть интерактивных учебных моделей: состояния Git, IPv4/CIDR, TCP, MMU, COW и зависимости systemd.

## Уровни обучения

Выбор уровня сохраняется независимо для каждого курса. Ссылки вида `#/lesson/git-merge/senior` фиксируют редакцию. Junior содержит доступные новичку объяснения и практику. Middle включает все темы Junior и полные технические редакции; базовое объяснение можно раскрыть дополнительно. Senior включает весь Middle, дополнительные главы и отдельные углубления. God пока повторяет содержание Senior и показывает будущий исследовательский маршрут — не готовый курс. Прогресс хранит максимальную прочитанную глубину; старые отметки чтения мигрируют без отметки новых дополнений Senior.

## План развития

Новые направления временно не открываем. Приоритет — завершённые маршруты и глубина 11 существующих курсов. Текущий фокус: Git. Расширение остановлено на этапе 6/8 для последовательной педагогической переработки всех существующих глав. Сквозной проект Git — Atlas Notes; десять глав переработаны, включая [три состояния Git](https://localzet.github.io/academy/#/lesson/git-index/junior). Новые блоки `:::learn <key>` вставляются непосредственно в учебный текст, реализованы в `academy/assets/teaching.js` и `teaching.css`; их модели, реальные команды и браузерные взаимодействия проверяются тестами. Техническая приёмка не равнозначна педагогической. Состояние и критерии перехода к следующему курсу описаны в [ROADMAP.md](ROADMAP.md). Не увеличиваем число глав за счёт искусственного дробления; проверяем команды и результаты практики.

## Разработка и проверка

```bash
python3 -m http.server 8080
# открыть http://localhost:8080/academy/
```

Из корня репозитория. Достаточно статического HTTP-сервера: никаких npm, сборки, API и сервера приложений.

## Дополнение курса

Добавьте запись через `window.ATLAS_DATA.lessons.push(...)` в соответствующий `academy/subjects/<subject>.js` с полями `id`, `course`, `title`, `summary`, `minutes`, `body` (Markdown), `sources`. Для кодовых блоков используйте ограду `~~~`, для inline-команд — `§команда§`. Обновите roadmap в `content.js`, если добавляется новая тема. Каждый ключ `sources` должен существовать в словаре источников каталога. В `levels.js` укажите минимальный уровень, порядковое место, а для Junior — отдельный текст, схему и вопрос. Для каждого дополнения Senior добавьте схему. Для каждой главы добавьте учебную цель, определения терминов, логическую схему и вопрос с ответом в `editorial.js`; при необходимости — отдельную иллюстрацию в `figures.js`. После правок запустите `node academy/tests/validate.mjs` из корня репозитория. Браузерные проверки запускаются в GitHub Actions через `.github/workflows/atlas-browser.yml`.
