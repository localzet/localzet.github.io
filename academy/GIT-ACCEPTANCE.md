# Git — протокол финальной приёмки

## Область

51 уникальная глава: 48 переработанных и три итоговых проекта. 115 чтений по уровням: Junior 21, Middle 43, Senior 51. God — будущий исследовательский маршрут, не четвёртый готовый уровень.

## Критерии

| Критерий | Проверка |
|---|---|
| Полнота и порядок | validate.mjs и git-final-audit.mjs: вложенные маршруты, отсутствие дублей, итоговый проект последним |
| Учебный интерфейс | Все маркеры зарегистрированы, отрисовываются, внутренние ссылки разрешаются; browser.cjs проверяет все 115 редакций в двух контекстах и репрезентативные взаимодействия в восьми |
| Сквозная практика | git-final-audit.mjs запускает весь последовательный Junior до проекта, включая ранее отдельный опыт индекса; 28 коммитов основного репозитория и синхронизация двух копий |
| Технические главы | Существующие специализированные тесты запускают команды на временных репозиториях; добавлен опыт criss-cross с двумя лучшими базами |
| Итоговые проекты | Три эталонных сценария и отрицательные тесты checker; не требуется точное совпадение OID с эталоном |
| Источники и ссылки | Проверка существования ключей источников, HTTPS, локальных ссылок и загрузки checker; доступность всех внешних URL непрерывно не гарантируется |
| Безопасность | Изолированные лаборатории, без реальных секретов и производственных репозиториев; явно указаны ограничения и разрушительные действия |
| Педагогика | Ситуация, объяснение, схема, практика, обратная связь, самостоятельная задача. Автотесты подтверждают структуру и поведение, но не усвоение материала |

## Исправления при аудите

- Junior index: отдельная папка index_lab, явный возврат в исходный Atlas Notes и проверка состояния.
- Junior diff: сценарий соответствует реальному app.conf. Junior commit: проверяется индекс перед сохранением, а не рабочий файл после commit.
- Merge: независимые участки вместо обещания автоматического слияния любых двух строк; задание на настоящий конфликт одной строки.
- Senior merge: несколько лучших общих предков, реальный граф X/Y с двумя базами и одинаковыми деревьями.
- Middle/Senior: предупреждение о последовательной практике Junior, единое вычисление времени в каталоге и главе.
- Автоматизация: проверка действительного порядка скриптов из index.html, расширенная навигация всех редакций.

## Граница приёмки

Готовность первой учебной редакции определяется успешным CI на коде аудита. Автоматическая приёмка не является сертификацией квалификации, доказательством усвоения, полной проверкой всех конфигураций Git или независимым тестированием людьми. Внешние источники могут меняться. Замечания реальных учеников остаются основанием для следующих исправлений.
