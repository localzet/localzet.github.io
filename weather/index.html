Мы не публикуем фиктивные оценки. Для сравнения ECMWF, ICON, GFS и нашего будущего ансамбля необходимы архивы прогнозов с временем выпуска и независимые наблюдения метеостанций.

Бэктест ещё не выполнен

Текущий сайт показывает настоящий прогноз Open-Meteo. Исторические ошибки, модельная коррекция и рейтинг по городам появятся только после верификации.

Принцип: сохраняем captured_at / valid_at, сопоставляем с проверенными наблюдениями, оцениваем MAE, Bias, RMSE, P95 и надёжность вероятностей осадков. Для всех моделей — одинаковые периоды; для обучения — отдельно от тестового набора.
